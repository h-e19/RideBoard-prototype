# RideBoard: Phase 2 prototype

A ride board web app, linked from a WhatsApp bot, that helps IBA students find and offer carpools between home and campus.

**Group:** Hijab Ejaz, Bareerah Shahid

To run it, open the link above, or download `index.html` and open it in a browser.

Mid-fidelity and grayscale, with working navigation. The WhatsApp bot is simulated. The left panel runs the Phase 3 tasks (T1–T6). The right panel shows which requirement each numbered marker on the phone maps to.

## Changes after the wireframes

- My rides split into **Driving / Riding**, because it was unclear whose rides were shown.
- Offers moved into a **swipeable popup** on each request card, so Home works with several requests.
- Board split into **Find a seat / Give a ride**, because offers and requests were mixed together.
- Tried a busier Home with a "Needs your answer" section. **Reverted**, because it duplicated items and felt cluttered.
